## Instructions
1. Clone the repository first and install the requirements packages :
   
   ```bash
   git clone https://github.com/mahdiadham/admin-dashboard.git
   cd admin-dashboard
   npm install
   ```
2. Start the project with command :
   
   ```bash
   npm start
   ```
3. Enjoy your modern template !
